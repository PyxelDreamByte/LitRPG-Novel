# WLD-RARITY-001D — Defer all universal rarity proportions

## Author disposition

Rarity distribution is **DEFERRED**. The project defines no universal rarity
percentages or default proportions.

This is a completed Author decision to postpone the subject, not an unanswered
request for an agent to invent values.

## Activation prerequisites

A scoped rarity-distribution decision may begin only after all six are defined:

1. object type;
2. rarity dimension;
3. eligible denominator;
4. population;
5. period; and
6. evidence base.

Examples of object type include Skills, classes, items, bloodlines, achievements,
or dungeons; none is selected here. A rarity dimension might concern offer
frequency, recognised grade, provenance, production difficulty, or another
declared measure; none is selected here.

## Boundary

This decision creates no setting fact and supplies no proportions. It prohibits
reusing one object's eventual distribution as a universal table for unlike
objects or populations.
