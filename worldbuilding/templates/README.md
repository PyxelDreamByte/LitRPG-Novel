# Worldbuilding Templates

- [`worldbuilding-proposal.md`](worldbuilding-proposal.md) — develop a setting-local candidate without promoting it.
- [`worldbuilding-decision.md`](worldbuilding-decision.md) — human review surface for a setting decision.
- [`accepted-world-record.md`](accepted-world-record.md) — human review surface for an accepted setting fact.
- `accepted-world-record.template.json` — validation-ready accepted record using the required `.worldbuilding.json` contract.
- `setting-manifest.template.json` — validation-ready source for a discoverable `<setting-slug>.setting-manifest.json`, using the story-integration setting contract.
- [`setting-constitution.md`](setting-constitution.md) — empty constitution for a future real setting.

Do not fill the setting templates until the Author begins a named setting. A
project default is adopted only when a work manifest explicitly names its
decision URI and scope.
