# Initial Ridge-Spur Lake-Road Practical Travel Scale

## Scope

This is the provisionally authoritative broad conditional fair-weather journey
scale for the road already established between Project Hearthway's initial
ridge-spur settlement and the lake.

## Provisional claims

1. The road uses the author-facing practical scale “half-day working route.”
2. Under the displayed fair-weather comparison, an ordinary unladen downhill
   journey has a broad 1–1½-hour reference band.
3. Under that comparison, a routine laden uphill return has a broad 2–3-hour
   reference band.
4. A useful shore visit followed by a loaded return can consume most of a
   working day.
5. The lake remains part of regular settlement life even though haulage,
   freshness where goods are perishable, remaining daylight, and delays can
   matter.
