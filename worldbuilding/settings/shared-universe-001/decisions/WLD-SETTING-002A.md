# WLD-SETTING-002A — Consolidate shared-setting authority into Project Hearthway

Decision URI: `author-decision://world/WLD-SETTING-002A`

## Question

Two Author-gated shared-setting bootstraps were created in parallel working
sessions and merged on 2026-08-17:

- `setting://continuity-one` — accepted initiation decision
  (`author-decision://world/WLD-CONTINUITY-INIT-001A`, 2026-08-12), empty
  authority shell, layered but unanswered foundation map, no adopting works;
- `setting://shared-universe-001` (Project Hearthway) — provisional identity
  (`author-decision://world/WLD-SETTING-001A`, 2026-08-13), adopted by
  `work://series/project-hearthway-main`, eighteen bounded provisional records.

Each branch's registers called its own container the first real shared setting.
Which container carries shared-setting authority going forward?

## Author selection

The Author selected **Fold into Hearthway** on 2026-08-17, from four options
(fold into Hearthway; keep both; retire Continuity One without absorption;
rebase everything onto continuity-one):

- `setting://shared-universe-001` remains the sole live shared-setting
  container.
- The authority topology accepted by Continuity One's `SET-INIT2A` — one
  shared setting core with governed compatible work-local overlays — is
  absorbed into the Project Hearthway setting constitution.
- `author-decision://world/WLD-CONTINUITY-INIT-001A` is superseded by this
  decision. The continuity-one shell is archived under
  `archive/settings/continuity-one/` with the supersession recorded in place;
  it remains provenance, never current authority.
- Continuity One's unanswered foundation map is not imported. Project
  Hearthway's own Author gates continue to govern its open questions.

## Explicit exclusions

This decision does **not** accept any geography, history, culture, species,
ecology, character, premise, plot, prose, project default, or story authority,
and does not change any of the eighteen bounded provisional Project Hearthway
records or CAL0.
