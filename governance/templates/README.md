# Governance Templates

- [`decision-record.md`](decision-record.md) — record a material Author choice.
- `decision-record.template.json` — validation-ready structured decision skeleton.
- [`review-finding.md`](review-finding.md) — report a stable, evidence-backed defect or recommendation.
- [`revision-change-set.md`](revision-change-set.md) — give one reviser an unambiguous approved task list.
- `workflow-evidence-manifest.template.json` — retained evidence for an Author-approved outcome.
- `live-evaluation-evidence-manifest.template.json` — promotion-forbidden retained evidence for a bounded live noncanonical evaluation.

Copy a template into the authoritative domain directory and replace every
bracketed field. A completed draft remains proposed until the Author records a
disposition. Accepted, provisional, deferred, and rejected dispositions all
require identifiable Author evidence.
