# Approved Change Set — WLD-FLORA-002

## Approved rule

Use bounded modular colony patches for the reserve-web guild in the initial basin:

1. Reserve-web subsurface networks are organized into bounded modular colony patches.
2. Each patch contains numerous rooted modules connected through a spatially
   limited living network.
3. Connected modules can share resources over limited local distances through
   living connections.
4. Damage can sever connections, isolate portions, and kill modules or sections.
5. Distinct patches do not form one continuous basin-wide organism.
6. Local resource sharing does not constitute shared consciousness.
