# Approved Change Set — WLD-FLORA-003

## Approved rule

Use threshold-based viability for severed reserve-web fragments:

1. Severance alone does not guarantee survival or a new patch.
2. A severed fragment can persist only when it retains enough viable modules,
   reserves, and functioning connections to sustain itself.
3. A viable fragment can slowly stabilize as an independent patch.
4. An inadequate fragment cannot sustain itself independently and declines and dies.
5. Fragmentation is a possible but non-automatic patch-founding route.
