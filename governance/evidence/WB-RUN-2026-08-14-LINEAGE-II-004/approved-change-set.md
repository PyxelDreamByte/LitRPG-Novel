# Approved Change Set — WLD-ECOLOGY-004

## Approved rule

Use a predictable peripheral migration corridor:

1. Crown herds normally use a principal lower-basin corridor near the initial settlement.
2. They normally pass the local area twice per annual cycle.
3. The fortified ridge-spur core is above and outside the principal route.
4. Secondary paths overlap some fields, roads, and lake approaches.
5. Ordinary passages cause closures, crop loss, and travel disruption rather than siege.
6. Severe weather, digestive disease, or forage failure can divert herds toward
   the settlement and create an exceptional crisis.
7. Ribbon groups create smaller, more frequent pressure around woodland and lake margins.
