# Approved Change Set — WB-RUN-2026-08-15-LOCATION-002

## Author-approved selection

On 2026-08-15, the Author selected `B — Half-day working route for the
practical lake-road travel scale`.

The binding selection establishes two broad fair-weather authoring anchors for
the road between the initial ridge-spur settlement and the lake:

1. `Downhill, unladen — 1–1½ hours`; and
2. `Uphill, laden — 2–3 hours`.

A useful shore visit followed by a loaded return can consume most of a working
day, while the lake remains part of regular settlement life.
