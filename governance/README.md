# Governance

This directory defines how creative and mechanical material becomes authoritative.

- [`AUTHOR-AUTHORITY.md`](AUTHOR-AUTHORITY.md) — decisions reserved to the Author.
- [`CANON-POLICY.md`](CANON-POLICY.md) — canon states and promotion rules.
- [`SOURCE-AUTHORITY.md`](SOURCE-AUTHORITY.md) — precedence when sources disagree.
- [`DECISION-POLICY.md`](DECISION-POLICY.md) — stable decisions and reconsideration.
- [`CONTEXT-ROUTING.md`](CONTEXT-ROUTING.md) — bounded context for agents and workflows.
- [`WORKFLOW-REGISTRY.md`](WORKFLOW-REGISTRY.md) — Author-callable workflows and gates.
- [`SUCCESSOR-VERSION-POLICY.md`](SUCCESSOR-VERSION-POLICY.md) — immutable CAL0 successor storage and activation.
- [`ACTIVE-SYSTEM-BASELINE.md`](ACTIVE-SYSTEM-BASELINE.md) — authoritative pointer to the active System baseline.
- [`evidence/`](evidence/) — retained workflow evidence promoted from the disposable workbench.
- [`templates/`](templates/) — reusable human-readable records.
- [`schemas/`](schemas/) — machine-readable governance contracts.
- [`evals/`](evals/) — fixtures for testing workflows and agents.

These files govern repository process. They do not themselves establish fictional facts unless an accepted decision explicitly does so.
