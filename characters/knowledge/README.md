# Character Knowledge

Knowledge records distinguish:

- causally true fact;
- source or observation;
- access and timing;
- interpretation and confidence;
- belief, suspicion, misconception, or deliberate lie;
- what may be presented through an interface;
- what has been disclosed to the reader.

Do not use author knowledge to make a character conveniently informed.

Store records inside the owning work using `../templates/character-knowledge.md`. Never merge knowledge from a same-named character in another work.
