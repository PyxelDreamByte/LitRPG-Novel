# Series

Each series begins with paired `work-manifest.md` and `<series-slug>.work-manifest.json`, `work-contract.md`, and an accepted series contract, followed by book contracts and scoped outlines. Series-wide facts do not automatically become world canon; promote them explicitly when they should govern stories outside the series.

Use `../templates/work-manifest.md`, `../templates/work-contract.md`, and `../templates/series-contract.md`. Declare whether the series adopts a shared setting, uses a local overlay, or has an independent setting. Global decisions apply only when explicitly listed.

Each book is unit token `book-##` at unit path `books/book-##/`. Chapter, delta, event, and snapshot URIs use the unit token; manuscript and state paths use the unit path.
