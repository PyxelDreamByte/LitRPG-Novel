# Novellas

Each novella has paired `work-manifest.md` and `<novella-slug>.work-manifest.json`, its own root, work contract, novella contract, characters, optional world overlay, outline, chapters, deltas, continuity, editorial evidence, context packs, and runs. Use the templates in `../templates/`.

Use unit token `main` and unit path `units/main`; keep chapter cards, manuscript chapters, state, continuity, and editorial evidence beneath that unit path.

Keep the cast, setting footprint, subplots, and progression envelope deliberately compressed. A novella never inherits a series or global setting merely because related files exist.
