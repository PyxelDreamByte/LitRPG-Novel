# Short Stories

Short stories may stand alone, explicitly extend accepted canon, or serve as noncanonical workflow pilots. Each has its own work manifest/root and declares which case applies before drafting.

```text
<story-slug>/
├── work-manifest.md
├── <story-slug>.work-manifest.json
├── work-contract.md
├── short-story-contract.md
├── characters/
├── world-overlay/
├── workbench/{context-packs,runs}/
└── units/story/
    ├── outline/chapter-cards/
    ├── manuscript/chapters/
    ├── state/{deltas,snapshots}/
    ├── continuity/
    └── editorial/
```

Use unit token `story` and unit path `units/story`.

For the first end-to-end council test, prefer a contained non-canonical story with enough world, character, and CAL0 pressure to exercise planning, review, delta creation, and acceptance without constraining the main novel.
