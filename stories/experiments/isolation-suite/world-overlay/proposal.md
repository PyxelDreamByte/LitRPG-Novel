# Evaluation world proposal — Salt Archive

The cliff archive stores memories on fired-glass tablets. Salt storms can expose sealed galleries, and keepers use keyed shutters to isolate them.

Deliberate flaw: the proposal asserts that WLD-SOUL and WLD-PRENATAL automatically govern the tablets because those decisions exist elsewhere in the repository. The independent-setting manifest adopts neither decision and adopts no default world guardrail.

This proposal is noncanonical and cannot be promoted.
