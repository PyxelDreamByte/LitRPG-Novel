- Resolve exactly one machine `work-manifest.json` or `*.work-manifest.json` plus its paired `work-manifest.md` before reading or writing work-local material. JSON is machine authority; any identity/boundary mismatch blocks work. Every character and story URI uses the manifest's typed work identity.

- A work declares `setting_scope`: `SHARED_WORLD`, `WORK_LOCAL`, or `INDEPENDENT_SETTING`. Never inherit WLD-SOUL, WLD-PRENATAL, default guardrails, or another work's overlay implicitly.
- `EVALUATION` is permanently noncanonical: promotion and updates to authoritative story, character, world, and System state are forbidden.
- The Author alone accepts outlines, chapters, canon deltas, voice, and publication text.
- Plan from the accepted work/unit contracts appropriate to the manifested form and a locked chapter card.
- One drafter or reviser owns the manuscript in each round; reviewers remain read-only.
- Preserve POV knowledge, causal feasibility, continuity, active threads, future destinations, and CAL0 rules.
- Treat every invented fact as proposed until classified in the chapter delta.
- Accept a chapter only as manuscript plus explicit delta; rebuild derived state afterward.
- Use Git history for revisions and stable IDs for chapters, scenes, events, threads, and findings.
